Get set up

Discovery-first outreach. Sourcing is fixed to Canonical; drafts are never auto-sent — you send by hand.

    1 · Agent

    coldtrail drives a headless agent. Pick the one it should use.

    2 · Connectors

    Canonical (sourcing) wires automatically. Gmail (drafts) needs a Google Cloud OAuth client — setup guide. Scopes: gmail.readonly, gmail.compose; redirect http://localhost:8765/callback.

    3 · Your pitch

    Your message template (message.toml). Placeholders {company} / {fn} fill per contact. Stays local.

    4 · Already contacted

    Domains you've reached before (contacted.toml) so coldtrail never double-contacts.

    Run the loop

    Tell the agent what you want. It sources via Canonical, enriches, and drafts — you review and send.
